# 1. Purpose

This document defines the constraints applicable to the QuickBite Food Delivery Platform.

Constraints represent limitations, boundaries, and mandatory conditions that influence system architecture, implementation, deployment, operations, governance, and project execution.

These constraints establish the operating boundaries within which the platform shall be designed, developed, tested, deployed, and maintained.

---

# 2. Scope

This document includes:

- Business Constraints
- Technical Constraints
- Infrastructure Constraints
- Security Constraints
- Regulatory Constraints
- Budget Constraints
- Resource Constraints
- Schedule Constraints
- Operational Constraints

These constraints apply throughout the Software Development Life Cycle (SDLC).
